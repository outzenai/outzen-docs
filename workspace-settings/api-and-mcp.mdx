You can work with your Outzen workspace from your own code or from an AI client. Both use a **personal access token** that acts as you, with your role and your workspace memberships.

## Create an API key

<Steps>
  <Step title="Open your profile">
    Open your **Profile** and choose the **API keys** tab. API keys belong to you, not to the workspace, so they're not under Settings.

    <Frame caption="Profile, API keys: your personal access tokens">
      <img src="/images/api-keys.png" alt="Profile, API keys: your personal access tokens" width="1280" height="800" />
    </Frame>
  </Step>
  <Step title="Create a token">
    Choose **New token**, give it a name, and pick an expiry or **Never expires**.

    <Frame caption="New personal access token: give it a name and an expiry">
      <img src="/images/api-new-token.png" alt="New personal access token: give it a name and an expiry" width="1280" height="800" />
    </Frame>
  </Step>
  <Step title="Copy it now">
    The token is shown once. Store it in a password manager or secret store. If you lose it, revoke it and create a new one.

    <Frame caption="The token is shown once. Copy it before you dismiss the banner (the value is hidden in this picture)">
      <img src="/images/api-token-banner.png" alt="The token is shown once. Copy it before you dismiss the banner (the value is hidden in this picture)" width="1280" height="800" />
    </Frame>
  </Step>
</Steps>

The list shows each token's status (active, expired, or revoked), when it was created, and when it was last used. Revoke a token and anything using it stops working immediately. Tokens start with `pat_live_`.

<Warning>
  A token can do everything you can do. It has no narrower scope, so treat it like a password, and use an expiry for anything temporary.
</Warning>

## REST API

The public API is documented interactively at [https://outzen.ai/docs/api](https://outzen.ai/docs/api), and the OpenAPI specification is available at [https://outzen.ai/api/v1/openapi.json](https://outzen.ai/api/v1/openapi.json). Send your token as a bearer token:

```
Authorization: Bearer pat_live_...
```

The API covers the main things you do in the app, including campaigns, Lists, prospects, companies, conversations, the Do-Not-Contact list, meetings, products, templates, and brand voice. Every call is checked against the same permissions as the app, so a token can only do what your role allows.

## MCP

Outzen runs an MCP server at `https://outzen.ai/api/mcp`. Any MCP-capable AI client — Claude, ChatGPT, Codex, Cursor — can connect to it and work on your workspace through a curated set of tools (check readiness, set up products and templates, build Lists, see where credits went, read the inbox, book meetings, and more). Tools never send outreach, never delete records, and only spend credits against a quote you agreed to. Every call is checked against your role in whichever workspace you're using.

Calls are rate limited per token.

### Connect Claude

Claude signs in to Outzen with your Outzen account — you don't need to paste a token.

<Steps>
  <Step title="Open connector settings">
    In Claude, open **Settings → Customize**, choose the **Connectors** tab (top left), then click **Add** (top right). (On Claude Desktop and Claude Web the entry point is the same.)
  </Step>
  <Step title="Point it at Outzen">
    Name it **Outzen** and set the server URL to:

    ```
    https://outzen.ai/api/mcp
    ```

    Leave authentication on the default — Claude discovers Outzen's sign-in automatically. Save and enable the connector.
  </Step>
  <Step title="Sign in">
    The first time you use the connector, Claude opens Outzen's sign-in page in your browser and asks you to approve the connection. Review what the connector can do and choose **Approve**. You're back in Claude once it finishes.
  </Step>
  <Step title="Try it">
    Start a Claude chat with the Outzen connector enabled and ask something like **"What's left to set up in my Outzen workspace?"** Claude calls `check_readiness` and reads your next steps back to you.
  </Step>
</Steps>

If you belong to more than one workspace, Claude asks which to use before any tool call. Switching workspaces is a question away — **"Switch to the Acme workspace"** — not a reconnect.

### Connect ChatGPT

ChatGPT signs in to Outzen with your Outzen account — like Claude, you don't need to paste a token.

<Steps>
  <Step title="Open Plugins">
    In ChatGPT, click **Plugins** in the left panel.

    If you don't see **Plugins**, your ChatGPT may still use the older route: open **Settings → Connectors**, turn on **Developer mode**, and choose **Add custom connector**. Name it **Outzen** and use the URL in the next step.
  </Step>
  <Step title="Add a custom MCP server">
    Click **Add** (top right) and choose **Add custom MCP server**. In the window that opens, enter **Outzen** as the **Name** and this URL as the **Connection**:

    ```
    https://outzen.ai/api/mcp
    ```

    Then click **Create as a plugin**.
  </Step>
  <Step title="Sign in">
    The first time you use the connector, ChatGPT opens Outzen's sign-in page in your browser and asks you to approve the connection. Review what the connector can do and choose **Approve**.
  </Step>
  <Step title="Try it">
    Start a ChatGPT chat with the Outzen connector enabled and ask something like **"What's left to set up in my Outzen workspace?"** ChatGPT calls `check_readiness` and reads your next steps back to you.
  </Step>
</Steps>

If you belong to more than one workspace, ChatGPT asks which to use before any tool call. Switching workspaces is a question away — **"Switch to the Acme workspace"** — not a reconnect.

### Connect other clients

- **Codex** — run `codex mcp add outzen https://outzen.ai/api/mcp`, then `codex mcp login outzen`.
- **Clients that can't do OAuth** — create a Personal Access Token above and paste it as a bearer token.

## If something's off

- **401 Unauthorized.** The token is missing, mistyped, expired, or revoked. Create a new one.
- **403 Forbidden.** Your role doesn't allow that action. See [Roles and permissions](/workspace-settings/roles-and-permissions).
- **Rate limited.** MCP calls are limited per token; slow down and retry.
